Troubleshooting

Start with the smallest relevant check. Most first-launch problems come from a plugin that is still downloading or a missing system runtime.

Quick health check

cd ~/config
./scripts/validate.sh
nvim

# Then, inside Neovim:
:checkhealth
:Lazy
:Mason

After a large first installation, close and reopen Neovim once. This lets newly installed parsers and language tools load in a clean process.

Plugins do not finish installing

  1. Open :Lazy.
  2. Press S to sync the declared plugins.
  3. Read the error for the individual failed plugin.
  4. Check internet access and confirm git --version works.
  5. Restart Neovim after the sync completes.

Language server does not attach

  1. Run :set filetype? and confirm the detected language.
  2. Run :Mason and confirm the matching server is installed.
  3. Run :LspInfo and inspect the server’s root directory and command.
  4. Open :LspLog if the process starts and immediately exits.

Node-based servers fail

TypeScript, ESLint, HTML, CSS, JSON, Bash LS, and Prettier require Node:

brew install node
node --version

R server fails

Install R, then reopen Neovim so Mason can complete the language-server installation:

brew install r
R --version

Formatting or linting does nothing

  • Run :ConformInfo to see the selected formatter and its executable.
  • Run :Mason to confirm Ruff, Air, Prettier, StyLua, shfmt, or ShellCheck is installed.
  • Formatting is not automatic. Press Space l f.
  • Zsh intentionally has no shfmt or ShellCheck integration.

LaTeX does not compile or open

Check each layer separately:

which latexmk
which open

# Install missing dependencies:
brew install --cask mactex-no-gui
brew install --cask skim

Inside a .tex file, run :VimtexInfo. Use \ l l to compile and \ l v to view.

Icons appear as question marks

Select MesloLGS Nerd Font in the active iTerm2 profile, then open a new terminal window. The Brewfile installs the font, but iTerm2 still needs to use it for both ASCII and non-ASCII characters.

Search does not find files

brew install fd ripgrep
fd --version
rg --version

Run Neovim from the project directory with nvim .. Snacks uses the working directory as the default search scope.

CSV or Markdown view

  • Use :CsvViewToggle in a CSV file.
  • Use :Markview toggle to change Markdown rendering.
  • If a command is unknown, open :Lazy and confirm the plugin loaded successfully.

Update safely

cd ~/config
git pull --ff-only
brew bundle install
./scripts/validate.sh

Open :Lazy and sync after pulling. Mason Tool Installer will reconcile the declared language tools when Neovim starts.

Restore the previous configuration

The installer gives displaced files names such as ~/.config/nvim.backup-YYYYMMDDHHMMSS. To restore one, first move the managed symlink out of the way, then rename the desired backup to ~/.config/nvim. Inspect the exact paths before moving anything.
