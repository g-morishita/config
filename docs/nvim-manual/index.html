Current configuration

A focused, animated Neovim.

This manual describes the configuration in this repository: no AI tools, one file sidebar, a clean Tokyo Night interface, and language tooling selected for everyday research and development.

Navigate

Neo-tree provides the sidebar. Snacks handles files, text, buffers, recent files, and Git search.

Write

Blink provides completion. Conform formats on request, while nvim-lint reports Python and shell problems.

Read

Markview renders Markdown, CSVView aligns tabular data, and VimTeX compiles LaTeX into PDFs with Skim.

See context

Tokyo Night, Lualine, Git signs, indentation guides, diagnostics, smooth scrolling, and cursor animation stay visible but restrained.

Install

Clone the repository and let the installer link the configuration and install its Homebrew dependencies:

git clone git@github.com:g-morishita/config.git ~/config
cd ~/config
./scripts/install.sh --packages

If the Homebrew packages are already present, omit --packages.

The installer moves an existing ~/.config/nvim to a timestamped backup before creating the symlink. It does not silently delete the previous configuration.

First start

  1. Run nvim.
  2. Lazy downloads the configured plugins.
  3. Mason downloads the configured language servers and command-line tools.
  4. Wait until installation is quiet, close Neovim, and open it again.
  5. Run :checkhealth if any warning remains.

Useful management screens:

CommandPurpose
:LazyInspect, update, or clean Neovim plugins.
:MasonInspect language servers, formatters, and linters.
:checkhealthRun Neovim and plugin diagnostics.
:LspInfoSee which language server is attached to the current buffer.

Daily workflow

  1. Open a project with nvim ..
  2. Press Space e for the Neo-tree sidebar.
  3. Press Space Space to find a file or Space / to search its contents.
  4. Use gd, gr, and K to explore code through the language server.
  5. Use Space l f to format and Space l l to lint.

What is installed

Interface

Tokyo Night, Lualine, web-devicons, Snacks indent, Which-key, Neoscroll, and Smear Cursor.

Editing

Blink completion, auto-pairs, Comment.nvim, Treesitter, HTML autotag, and persistent undo.

Code intelligence

Native Neovim LSP, Mason, BasedPyright, Ruff, Air, TypeScript, ESLint, and the other tools listed in the language matrix.

Special formats

Markview for Markdown, VimTeX and Skim for LaTeX, CSVView for data, and Colorizer for CSS colors.

Editor behavior

  • The leader and local leader are both Space.
  • Line numbers are absolute on the current line and relative elsewhere.
  • Tabs expand to two spaces; new splits open below or to the right.
  • Search ignores case unless the query contains uppercase letters.
  • The system clipboard is used for normal copy and paste.
  • Trailing whitespace is removed and missing parent directories are created when a file is saved.
  • Markdown and Git commit buffers enable wrapping and spell checking.
  • Format-on-save is disabled; formatting is an explicit action.
