How tools are used

LSP

Starts automatically for a matching project and provides completion, definitions, references, diagnostics, rename, and code actions.

Formatting

Run it explicitly with Space l f. If no dedicated formatter exists, Conform may use the attached LSP.

Linting

Ruff and ShellCheck run after entering or saving a buffer and after leaving insert mode. Use Space l l to run manually.

Parsing

Treesitter improves highlighting and structural understanding for Bash, CSS, Dockerfile, HTML, JavaScript, JSON, LaTeX, Lua, Markdown, Python, R, RNoweb, TSX, TypeScript, Vim, and YAML.

System dependencies

The repository’s Brewfile supplies:

brew bundle install
  • node for npm-based language servers and Prettier
  • r for R and its language server
  • fd and ripgrep for fast file and text search
  • skim as the LaTeX PDF viewer

A TeX distribution is intentionally separate because it is large:

brew install --cask mactex-no-gui
