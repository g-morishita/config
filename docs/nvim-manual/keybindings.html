Keybindings

Leader means Space. Press Space and pause to let Which-key show available groups.

Files, search, and Git

KeysModeAction
Space eNormalToggle Neo-tree.
Space SpaceNormalSmart file search.
Space /NormalSearch text in the project.
Space ,NormalSearch open buffers.
Space f rNormalOpen a recent file.
Space g sNormalSearch changed Git files.
Space g lNormalBrowse the Git log.
Space u nNormalDismiss notifications.

Inside Neo-tree

Use l to open a file or directory and h to close a directory. Standard Neo-tree mappings such as a for add, d for delete, r for rename, and ? for help remain available.

LSP and diagnostics

These buffer-local mappings appear when a language server attaches.

KeysModeAction
gdNormalFind definitions.
gDNormalGo to declaration.
grNormalFind references.
giNormalFind implementations.
gtNormalFind type definitions.
KNormalShow documentation under the cursor.
Space c aNormal / VisualShow code actions.

Space DNormalSearch all diagnostics in the buffer.

Editing

KeysModeAction
Space l fNormal / VisualFormat the file or selected range.
Space l lNormalRun the configured linter.
gccNormalToggle a line comment.
gc + motionNormal / VisualToggle line comments over a motion or selection.
gbcNormalToggle a block comment.
gco / gcONormalAdd a commented line below / above.
< / >VisualIndent and keep the selection active.
pVisualPaste without replacing the yank register.
xNormalDelete a character without replacing the yank register.

Windows, tabs, and movement

KeysAction
Option + h/j/k/lMove between windows.
Option + TabSwitch to the alternate buffer.
Shift + TabOpen the current file in a new tab.
Shift + h / lPrevious / next tab.
Ctrl + j / kSmooth half-page scroll down / up.
j / kMove by displayed lines when text wraps.
n / NNext / previous search result, centered.
Ctrl + ;Leave terminal mode.

Completion

KeysAction
Ctrl + jSelect the next completion item.
Ctrl + kSelect the previous completion item.
EnterAccept the selected completion item, otherwise insert a normal newline.

Markdown, LaTeX, and CSV

Keys or commandAction
:Markview toggleToggle rendered Markdown.
\ l lStart or stop continuous LaTeX compilation.
\ l vOpen the compiled PDF in Skim.
:CsvViewToggleToggle aligned CSV display.
Tab / Shift + TabMove to the next / previous CSV field.
Enter / Shift + EnterMove to the next / previous CSV row.
if / afSelect inside / around a CSV field.

The backslash is VimTeX’s default local leader. Run :VimtexInfo inside a .tex file to inspect its active mappings and compiler.
